# Baba Café & Restro — Android App

A modern, high-performance Android mobile application for **Baba Café & Restro** (Jaipur) built with **Kotlin**, **Jetpack Compose**, and the **Bloom Design System**.

## 🚀 Features
- **Bloom Design System:** Flat saturated field blue, bone cream display typography, 1px hairline borders, and single deliberate pollen accent.
- **Complete 14-Category Menu:** Over 60 verified items with accurate pricing (Teas, Coffees, Maggie, Breakfast, Continental, Fries, Shakes, Mocktails, Sandwiches, Momos, Chinese Starters, Rolls, Pizzas, Noodles).
- **Item Customizer:** S/M/L portion sizes, Dry vs Gravy options, and special chef cooking notes.
- **Cart & Direct Ordering:** Dine-in table selector, Takeaway, and Delivery with gateway-free billing (Pay at Counter / UPI QR / Cash).
- **Table Reservation:** Reserve tables for solo or group dining.
- **Cafe Info & Navigation:** 7A Gopalpura Bypass Rd Jaipur with one-tap Google Maps directions and dialer.

## 📦 Automated APK Build (GitHub Actions)
This repository includes a preconfigured GitHub Actions workflow (`.github/workflows/build-apk.yml`) that automatically builds and outputs the ready-to-install debug APK artifact (`BabaCafeApp-Debug-APK`) upon every commit/push.

### How to download your APK:
1. Go to the **Actions** tab in your GitHub repository: [github.com/madhavagarwal12/cafe-app/actions](https://github.com/madhavagarwal12/cafe-app/actions)
2. Click on the latest workflow run: **Build & Package Android APK**
3. Under **Artifacts** at the bottom of the page, download **`BabaCafeApp-Debug-APK`**.
4. Extract the zip and install the APK on your Android phone!
